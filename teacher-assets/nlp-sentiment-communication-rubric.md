# Sentiment Analysis Communication Rubric

## Coursework Task
**Coursework Task: Sentiment Analysis with Error Analysis**

Build a sentiment classification model for movie reviews and critically evaluate its performance.

### Requirements
- Use any dataset, such as IMDb or a small custom review dataset.
- Train a basic model, for example logistic regression or a simple neural network.
- Report the methodology, evaluation metrics, and the reasons behind your design choices.
- Include evaluation metrics such as accuracy and F1 score.
- Perform error analysis and identify where the model fails.
- Reflect on limitations and realistic improvements.

### Deliverable
Write a 1500-2000 word report with an Introduction, Methodology, Results, Error Analysis, and Conclusion.

## Rubric Focus
This rubric scores the communication of ideas in the report.

### Atomic Criteria
- `document_structure`
- `language_clarity`
- `technical_explanation`
- `analysis_depth`
- `referencing_and_academic_integrity`

## Band Mapping
| Band | Score Range | Description |
| --- | --- | --- |

## Criterion Definitions
### Document Structure (`document_structure`)
- Logical flow between sections
- Proper use of headings and report sections
- Clear transitions between ideas

### Language Clarity (`language_clarity`)
- Grammar and sentence control
- Formal academic tone
- Readable, precise wording

### Technical Explanation (`technical_explanation`)
- Correct explanation of the model
- Appropriate use of technical terminology
- Clear reasoning for design choices

### Analysis Depth (`analysis_depth`)
- Insight into results
- Quality of error analysis
- Evidence of critical thinking

### Referencing and Academic Integrity (`referencing_and_academic_integrity`)
- Proper citations and attribution
- No plagiarism or copied analysis
- Transparent GenAI use where relevant

## Teacher Guidance
- Use the rubric text as the source of truth when grading.
- Score the new submission against the communication criteria, not generic writing advice.
- Use the example calibrations to stay aligned to the intended band boundaries.

## Calibration Examples Summary
### Weak Example
- Score: 45/100
- Band: 40-49
- Reason: Very vague methodology description, no clear structure between sections, limited technical explanation, minimal error analysis, and informal language throughout.

### Average Example
- Score: 62/100
- Band: 60-69
- Reason: The methodology is clear and the structure is serviceable, with some awareness of model limitations, but the error analysis is still shallow and the transitions between ideas remain weak.

### Strong Example
- Score: 78/100
- Band: 70-84
- Reason: Strong technical explanation, insightful error analysis, clear formal language, and a logical progression of ideas, though the discussion could still use more quantitative error breakdown and dataset bias analysis.

### Excellent Example
- Score: 90/100
- Band: 85+
- Reason: Deep analytical insight, precise technical language, strong linkage between results and limitations, a professional academic tone, and well-justified next-step improvements.
