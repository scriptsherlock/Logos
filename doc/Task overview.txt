1) Task overview

The goal is to build a sentiment analysis classifier that predicts whether an IMDB movie review is positive or negative. I treat this as a binary classification task because the dataset labels are Positive/Negative and the goal is to predict the reviewer’s overall verdict.

Success criteria: evaluate on unseen reviews using accuracy, precision, recall, and F1, plus a confusion matrix to inspect false positives vs false negatives.

2) Dataset

I used the IMDB movie reviews dataset with the provided train/test split (25k train / 25k test, ~50k total). Labels are roughly balanced (commonly reported as ~50/50 positive/negative), which makes accuracy a reasonable starting metric, but I still report F1 to ensure performance isn’t hiding class-specific issues.

Examples (general):

Positive reviews often include strong positive descriptors (“great”, “amazing”, “loved”)
Negative reviews often include strong negative descriptors (“boring”, “waste”, “terrible”)

Dataset challenges I noticed:

Mixed sentiment: “great acting but boring plot”
Negation: “not good”
Sarcasm/irony: meaning differs from literal words
3) Approach / model

I implemented a baseline model:

Model: Logistic Regression
Features: Bag-of-words word counts (unigrams)

Why this baseline:

Simple, fast, and commonly used for text classification
Provides a strong reference point before trying more complex methods

Key settings (for reproducibility):

Vectorizer: CountVectorizer (unigrams, max_features tuned)
Classifier: Logistic Regression with L2 regularization (C=1.0 default unless tuned)

If I were improving this further, the next step would be TF-IDF + bigrams or a linear SVM, since bigrams can better capture phrases like “not good”.

4) Preprocessing

I used basic preprocessing:

Lowercasing
Removing extra whitespace
Removing some punctuation
(If applicable) removing HTML tags like <br /> in IMDB reviews

I did not remove stopwords aggressively because words like “not” matter for sentiment. I also did not use stemming/lemmatization.

5) Evaluation

I evaluated on the test set.

Accuracy: ~0.84

To make the evaluation more complete, I also computed:

Precision / Recall / F1 (positive class)
Confusion matrix (TP, FP, TN, FN)

Example interpretation:

A common failure mode is false positives where the model predicts positive due to a positive word early in the review, even if the conclusion is negative.

6) Error analysis & iteration

I reviewed several incorrect predictions and found two patterns:

Sarcasm / irony
The model struggles when the literal words look positive but the intent is negative.
Mixed reviews + final verdict
Example (paraphrased):
“This movie had good acting but overall it was disappointing.”
The model can predict positive because it heavily weights “good” and misses the overall negative conclusion.

What I would try next (concrete iteration):

Add bigrams so phrases like “not good” are captured
Switch to TF-IDF to reduce the impact of common words
Compare against a slightly stronger baseline (TF-IDF + Linear SVM)
7) Limitations
Domain-specific: trained on movie reviews, may not generalize to tweets or product reviews.
Keyword reliance: bag-of-words models can miss sentence structure, sarcasm, and long-range negation.
Ambiguity: some reviews contain both positive and negative statements but only one label.
Conclusion

I built a baseline sentiment classifier using bag-of-words + logistic regression and achieved ~84% accuracy on the IMDB test set. The model performs reasonably but struggles with sarcasm and mixed sentiment. A clear next improvement would be TF-IDF + bigrams to better capture negation and phrase-level sentiment.
