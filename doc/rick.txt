1) Task overview

The goal was to build a sentiment analysis model that predicts whether a review is positive or negative. I used a binary classification setting because the dataset labels are positive/negative. The model takes text reviews as input and outputs one of the two classes.

2) Dataset

I used the IMDB movie review dataset. It has a lot of reviews and the labels are positive or negative. I used the given train/test split. I did not deeply analyze label distribution, but it seems roughly balanced based on how the dataset is usually described.

Example reviews (general):

Positive reviews tend to have words like “great”, “amazing”, “loved”.
Negative reviews tend to have words like “bad”, “boring”, “waste”.
3) Approach / model

I tried a simple machine learning approach.

Model: Logistic Regression
Features: Bag-of-words (word counts)

Why I chose it:

It is easy to implement and commonly used for text classification.

I didn’t experiment with many different models, but I did change a few settings like max features.

4) Preprocessing

I did basic preprocessing:

Lowercased the text
Removed some punctuation
Removed extra spaces

I didn’t do stemming or lemmatization. I also didn’t do anything special for negations.

5) Evaluation

I evaluated the model on the test set using accuracy.

Accuracy: ~0.84 (around 84%)

I did not compute precision/recall/F1 in detail, but accuracy seemed okay for a baseline. I also did not include a confusion matrix.

6) Error analysis

I looked at a few wrong predictions manually. Some cases that seemed difficult:

Sarcasm (model gets confused)
Reviews that contain both positive and negative opinions

Example (paraphrased):
“This movie had good acting but overall it was disappointing.”
Sometimes the model predicted positive because it saw “good”.

I didn’t implement fixes, but maybe using bigrams or a better model could help.

7) Limitations

This model might not work well outside movie reviews. Also, it can be wrong when people use sarcasm or complicated writing. It also might depend a lot on keywords rather than understanding the sentence.

Conclusion

I built a logistic regression sentiment classifier using bag-of-words features. It achieved about 84% accuracy on the test data. The model works reasonably but struggles with sarcasm and mixed reviews.
